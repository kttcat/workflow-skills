# Verify an official list item by item

## Get the primary source for each item

- Open the primary official document for the list and read the entry for each item yourself.

- Treat a delegated summary, a prior list, or a search result snippet as a lead and not as proof for any item it names.

- Keep the page, section, or item number beside each checked item so a later reader can repeat the check.

- Mark an item unverified when its primary entry cannot be opened and keep it out of a verified claim.

## Classify each item by its exact wording

- Copy the status wording for each item and place it in only one class such as required, optional, or recommended.

- Treat a recommended level as a recommendation and not as a blocking requirement when the source does not call it a requirement.

- Treat a required document as required even when one part of it is optional and name the optional part separately.

- Check a score, level, or fee against the same entry and do not carry a value from a different item into it.

## Check completeness before claiming a list is complete

- Count the items you checked and compare that count with the count the source states for the list.

- Name the items you did not check and the sections you did not read when the count does not match.

- Rebuild a list from the source when a prior list is found to contain an error and do not patch only the item the user challenged.

- Void the prior list in the delivery when a rebuild changes it and name the items that changed.

## Present only what the source shows

- Present each item with its checked status and its source location and keep unverified items labelled unverified.

- Say plainly when a list is partial and list the unchecked sections beside the partial result.

- Run the approval check separately when a delivery also claims a decision is approved or final.

## Alternatives for better results

- Ask the user for the primary document when a delegated summary is the only source available.

- Split a long list into one pass for status, one pass for scores or fees, and one pass for completeness so one pass does not hide a mismatch.

- Keep a corrected list and its source locations together so a later correction can be checked in one place.
